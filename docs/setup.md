# 在工作台连接账号

想把同一组图文发往多个平台时，每个账号只需在自己的工作台完成一次连接。打开「渠道连接」，点击对应平台的「配置渠道」。保存的字段立即生效，重启后仍会保留。

| 平台 | 首次填写 | 如何确认 |
| --- | --- | --- |
| X | 在开发者应用开启读写权限并登记工作台显示的 OAuth 回调地址。填入 Client ID，机密客户端再填 Client Secret。 | 保存后点击授权，回到工作台看到「已连接」。 |
| LinkedIn | 开启 Share on LinkedIn，网页 OAuth 填入 Client ID、Secret 和已登记的 HTTPS 回调。若需要自动获知个人 URN，同时开通 OpenID Connect。 | 按提示完成授权。开发者应用获批原生 PKCE 时，可在更多选项中切换为本机回环模式。 |
| 小红书 | 启动自托管 xiaohongshu-mcp 后，点「检测本机连接器」检查 127.0.0.1 的 18060 端口，也可手动填入口地址。启用桥接鉴权时，在更多选项填写令牌。 | 保存地址，点击「获取登录二维码」并用小红书 App 扫码，随后检查登录状态。 |

X 与 LinkedIn 也可以使用已有个人用户令牌。LinkedIn 固定令牌需要同时填写作者 URN。X 的应用级搜索令牌单独填写在更多选项中。小红书桥接运行在容器中时，两个容器映射字段分别填写宿主机媒体目录和容器内共享目录。各平台的开发者控制台、回调转发方法、图片限制及容器挂载示例见[渠道指南](channels.md)与[小红书桥接指南](xiaohongshu.md)。

## 修改与清除

- 字段显示「已设置」表示工作台已经保存，留空可以沿用。要移除字段，请勾选「清除」并保存。
- 字段显示「环境变量管理」表示命令行环境或项目的 `.env` 已提供非空值。这些值优先，修改它们后需要重启。删除环境设置后，如果曾经用表单保存过同一字段，原表单值会重新生效。
- 更换小红书桥接地址会清除表单中与旧地址绑定的令牌。若环境变量管理桥接令牌，桥接地址也需由同一环境指定。
- 表单数据保存在数据目录的 `local-settings.json`，在 macOS 和 Linux 上文件权限为 0600。页面接收字段的配置状态，凭证值仅由本机服务读取。默认数据目录是项目根目录的 `.data/`，可通过 `OPEN_SOCIAL_DATA_DIR` 更改。

## 验证发布流程

先在「创作编辑器」选择三个平台、添加图片并填写文案，使用「本机演练」提交。前往「发布队列」，三份回执都应显示「演练完成」。连接好账号后，在编辑器切换到「真实发布」即可提交给相应平台。提交后让后台服务继续运行，浏览器可以关闭。
