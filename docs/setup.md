# 用自己的浏览器账号发布

如果你平时就在浏览器里发帖，可以沿用相同的登录方式。Open Social 负责保留三个平台各自的文案和图片，发布结果由你在平台上核对。

1. 在「渠道连接」点击对应平台的「官网登录」。在平台官网检查账号和头像，小红书可按创作中心提示扫码。以后从同一浏览器打开该平台时，可以继续使用它自己的登录会话。
2. 在「创作编辑器」勾选目的平台，写文案并添加图片。切换平台预览检查内容。例如，缩短 X 文案，给小红书单独写一个标题，保留 LinkedIn 的长版本。
3. 选择「网页发布」，点击「准备 3 个平台」（数量随勾选项变化）。队列会保留每个平台的图文，关闭网页后再打开也能继续。
4. 在队列里按下表操作，或在对应平台点「复制给 Computer Use」，把这条任务交给浏览器助手准备图文。你可以在平台编辑页检查账号、文案和配图，再点发布。看到平台自己的提交结果后，回工作台点击该渠道的「我已在平台发布」，它会显示「本人已确认」。

| 平台 | 从队列到官网 |
| --- | --- |
| X | 打开发帖页时自动带入 X 版正文。检查文本并附上配图，最后在 X 中发送。 |
| 小红书 | 点击「复制标题」「复制正文」，打开创作中心，粘贴内容并上传配图。按创作中心提示确认笔记。 |
| LinkedIn | 点击「复制正文」，打开动态编辑器，粘贴 LinkedIn 版文案，添加图片并发布。 |

队列的「发布配图」提供下载。浏览器支持时，还会显示「复制图片」或「系统分享」。打开网页、复制素材和系统分享之后，任务会保留为「待网页发布」，直到你本人确认。

## 先试一次

在编辑器选择「本机演练」并提交。队列中每个选定渠道都应显示「演练完成」，草稿仍可继续编辑。这个步骤可以在登录社交账号之前完成。

## 让后台代发

需要在关闭编辑器后自动投递时，打开「渠道连接 → 自动投递设置 → 配置渠道」。X、LinkedIn 可填写自己的应用凭证并完成 OAuth，小红书可以连接自己运行的桥接器。连接状态为「已连接」后，在编辑器选择「自动投递」。保持本机服务和所需连接器运行，队列将记录各平台回执。[开发者权限与 OAuth 回调](channels.md) · [小红书桥接设置](xiaohongshu.md)

表单保存后立即生效。已设置的字段留空会保留原值，勾选「清除」再保存会移除对应值。显示「环境变量管理」的字段来自启动环境或项目的 `.env`，这些非空值优先，修改后需重启服务。移除环境设置后，之前用表单保存的同名值可能重新生效。

更换小红书桥接地址会清除与旧地址绑定的表单令牌。如果令牌由环境变量提供，桥接地址也需由环境变量指定。表单配置保存在服务端数据目录的 `local-settings.json`，macOS 和 Linux 上文件权限为 0600。浏览器收到的是字段设置状态。
